# 公司 ERP 分析插件

在 DeepSeek Harness（DSH）中使用本人 ERP 账号开展经营、SKU、备货、广告和财务分析。插件提供统一的 11 套公司方法；业务数据由 ERP 按本人权限提供，模型由使用者在 DSH 中选择。

当前版本：**1.1.5**。适用于 Windows DSH，最低版本 `0.2.1-rc.3`。

## 从 GitHub 安装

1. 在 DSH 打开“插件 → 添加插件”。
2. 在“包名或地址”填写：

   ```text
   github:Huazhufather/DSH_USEC
   ```

3. 点击“安装”，安装完成后点击“立即启用”，按提示重启 DSH。
4. 打开左侧“公司 ERP 分析”，点击“登录 ERP”，打开显示的链接并核对本人账号。浏览器账号不对时点击“换个账号登录”。
5. 返回 DSH 刷新状态，确认当前账号后点击“开始公司分析”。

如需固定安装本次版本，填写：

```text
github:Huazhufather/DSH_USEC#v1.1.5
```

ERP 管理员须先为该账号开启“允许 DSH 接入”。安装插件本身不授予 ERP 数据权限。

## 登录、切换与退出

面板显示当前 ERP 账号，登录记住 30 天。同一人可以在多台电脑登录，电脑名称只用于识别登录来源。

- **切换账号**：自动退出当前电脑的旧授权，再提供新登录链接。登录新账号后，新建公司分析对话。
- **退出登录**：退出当前电脑的 ERP 授权，不影响其他电脑。
- 浏览器中的 ERP 会话独立；确认页面的“换个账号登录”可退出该浏览器会话，再沿原 ERP 入口登录。

旧分析连接在切换后停止 ERP 调用。待共享报告保留原归属，不会以新账号上传；原有聊天和工作文件保留在本机。

## 更新插件

GitHub 安装来源使用手动更新：完成当前分析，在 DSH 插件管理中卸载公司插件，再使用同一 GitHub 地址重新安装、立即启用并重启 DSH。新建公司分析对话使用新版。

本机登录和工作资料位于 `%LOCALAPPDATA%/CompanyDSH`，与插件安装目录分开，正常更新和重新安装会保留。

## 公司方法与报告

插件内含经营复盘、SKU 策略、库存与供给、运输方案、广告复盘、产品成本、平台利润、平台结算、公司财务、现金安排及企业知识方法。

正式报告在用户明确要求生成或保存后集中共享，已开启 DSH 接入的成员均可读取完整报告，包含成本和利润。普通聊天、草稿和临时附件保留本机。公司知识与共享报告从 ERP 读取，内容变化无需重新安装插件。

## 仓库内容

本仓库提供可直接安装的插件成品：`package.json` 和插件入口位于根目录，`release.json` 内嵌固定版本的工具及方法资源，安装时无需在同事电脑构建。
